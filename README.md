## Getting Started

This project is a starting point for a Flutter application.

📱 Gadget-Max

Flutter + Firebase E-Commerce Application

Gadget-Max is a mobile e-commerce platform that allows users to browse and purchase products such as Mobile Phones, PCs, Tablets, Accessories, and Gaming PCs. The system provides a smooth shopping experience for users and powerful management tools for administrators.

📌 Project Overview

This project was developed during a three-month internship (May to July).
It uses Flutter for the frontend and Firebase for real-time database, authentication, and cloud storage.
A new Flutter project.

Users can:

Register and log in

Browse categories and brands

Select models with color/storage options

Add items to the cart

Proceed to checkout and place orders

Admins can:

Manage categories, brands, and models

Upload product images

View user orders

Update or delete product data

🎯 Objectives

Build a functional e-commerce mobile application used for purchasing tech products.

Provide a seamless customer experience with cart management and order tracking.

Gain hands-on experience with Flutter, Firebase, and mobile app development.

🚀 Features
User Features

Explore product categories

View detailed product specifications

Choose colors, storage options, and quantities

Add products to cart

View order history

Generate invoice PDFs

## Admin Features

Admin login

Add, update, and delete categories, brands, and models

Upload multiple images for each model

Manage orders and user delivery details

## 🧱 System Design

The system contains two main actors:

User

Browse and purchase products

Manage delivery details

Track orders

Admin

Log in with credentials

Manage categories, brands, and models

Monitor user orders and inventory
